# Linux engine data

Reference data for the Linux engine, read locally (MemoryGraph never goes online). Put here, in the same shape as `app/engines/windows/data/attack_techniques.json`:

* `attack_techniques.json`: the ATT&CK techniques the Linux rules map to (tactics, a short summary, what to look for);
* known-good lists made from clean systems of the distributions you investigate (see `app/analysis/known_good.py` for the idea).
